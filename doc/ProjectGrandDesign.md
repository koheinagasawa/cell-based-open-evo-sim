# 人工生命プロジェクト：グランドデザイン

この文書は、本プロジェクトの中核となる設計思想とアーキテクチャ定義をまとめたものである。
出発点は、カンブリア爆発や思弁的な進化の世界に見られるような「ありえたかもしれない生き物」への関心である。
人間が個々の生き物の造形や動きを設計せず、進化計算と細胞レベルの相互作用から、多様な身体とその身体に応じた振る舞いを生み出せるかを探究する。

本プロジェクトは、「生命とは何か」の理論的定義だけを目的としない。
Open-Ended Evolution（OEE）は長期的な方向性であり、その達成だけでなく、進化による形態・行動の多様化や機能の積み上げも重要な成果とする。

人間が設計するのは、物理・環境の法則、相互作用の基本操作、遺伝表現などの成立条件である。
個体ごとの完成形や動作手順を与えるのではなく、その条件の中で身体や機能が進化から生まれることを目指す。
以下は設計目標と長期構想を含む。実装済み機能の一覧ではなく、現状と着手順は `roadmap_ja.md` を参照する。

## 1. コア・コンセプト：Emergent Semantics（創発的意味論）

設計の中心は、**生成規則を再利用し、その用途を増やすことで、発生から行動までを累積的に進化させること**にある。
そのために、進化における「構造の生成」と「意味（機能）への接続」を分離する。
トップダウンに「スロット0は移動、スロット1は攻撃」と決め打ちするのではなく、それらの割り当て自体を進化させる。

### 三位一体の創発メカニズム
1.  **Genome (Structure):** 間接表現により、用途を固定しない空間的パターンや信号（Raw Vector）を生成する。
2.  **Profile (Context):** 発生過程で決まる細胞ごとの「文脈」を提供する。
3.  **Interpreter (Mapping):** 直接表現により、文脈に応じて生成されたパターンを機能へ接続する。

### 分離するもの：生成規則とその用途

Genome は間接表現（Indirect Encoding）を用い、対称性や反復などの規則性を持つ複雑なパターンを記述する。
Interpreter は直接表現（Direct Encoding）を用い、そのパターンをどの機能へ接続するかを明示的に記述する。
この分離により、生成規則そのものの変更に加え、**大規模な Genome 構造の変更なしに、Interpreter や Profile の生成・選択規則の変更によって細胞の挙動を多様化する経路**を用意する。

狙いは、獲得済みの生成能力を毎回作り直すのではなく、別の文脈や用途へ展開して進化の足掛かりにすることである。
同じ入出力関数を表現できても、遺伝表現と変異操作が異なれば、どのような個体へ変化しやすいかは異なる。
ここで重視するのは表現力だけでなく、既存の個体から新しい形態・行動へ到達する変更経路である。

### Profile の役割：用途の置き換えだけでなく、追加を可能にする

同じ Genome と Interpreter を Agent 内の細胞で共有しながら、細胞ごとの Profile に応じて解釈を変える。
ある文脈では既存の機能を保ち、別の文脈では同じ生成規則を新しい機能に利用できれば、用途を共存させられる。
Profile は単なる細胞の分類ラベルではなく、**生成規則の異なる使い方を共存させる文脈**である。
既存の用途を失う「置き換え」と、用途を共存させる「追加」は区別して考える。

これにより、同じ遺伝的構造が新たな機能に転用される **Exaptation（外適応／転用）** の可能性を開く。
ただし、Profile ごとに異なる解釈が存在するだけで、進化の歴史の中で転用や機能の積み上げが起きたことになるわけではない。

### 統一するもの：形態生成と行動制御

形態を作るための専用システムと、完成した身体を動かすための別の制御器を用意するのではなく、
**Genome + Interpreter という単一のフレームワークで、発生から行動までを扱う。**
細胞は局所的な入力や State をもとに分裂・移動・信号伝達などを行い、その結果として身体や環境との関係が変わる。
変化した身体・近傍・Field は次の入力となり、同じ仕組みによる次の振る舞いへつながる。

たとえば、同じ空間的な反復パターンを、ある細胞群では分裂位置の偏りに、別の細胞群では収縮の強弱に利用することを構想する。
身体は行動の対象であると同時に、その局所的な振る舞いから形成されるものでもある。
発生と行動で役割や活動時期が分かれることは許容するが、別々の遺伝表現や設計済みの動作手順を必須としない。
Cell 生成後に Profile を固定する場合でも、State や周囲の条件が変わることで振る舞いは変化できる。

### 設計意図と、まだ保証されないこと

この分離の主目的は「進化の安定性の保証」ではなく、**既存の生成規則を利用しながら機能を拡張できる経路を設けること**である。
直接表現でも、一つの割当変更が多数の細胞に作用して個体を壊すことはある。
間接表現も、機能的なモジュール性や累積的な進化を自動的に保証しない。
用途の追加が実際に成立し、発生・行動を経て子孫にも受け継がれるかは、変異操作、発生過程、環境下での選択を通じて確かめる設計仮説である。

## 2. 構成要素の定義

### Genome = 意味未定の構造生成器
- **役割:** 空間的なパターンや信号の構造を作り出すことのみに専念する。
- **実装:** 間接表現（CPPN: Compositional Pattern Producing Network）を採用。
- **特徴:** 出力ノードは「移動」や「攻撃」といったラベルを持たず、単なる座標やベクトルとして扱われる。
- **共有と再利用:** 同じ生成規則を Agent 内の細胞で共有し、形態生成と行動制御の両方に利用する。
- **進化:** Agent単位で変異・交配する。

### Interpreter = 文脈依存の意味解釈器
- **役割:** Genomeの生の出力を、具体的なアクション（Move, Emit, Budなど）のスロットにマッピングする。
- **実装:** スロット割り当てリストなどの直接表現（Direct Encoding）。
- **特徴:** 単一の固定マッピングではなく、**CellのProfile（文脈）に応じて解釈ルールを切り替える** 機能を持つ。
    - 例：Profileが「筋肉」なら出力Aを「収縮」と解釈し、Profileが「神経」なら出力Aを「信号伝達」と解釈する。
- **進化:** スロット割り当て（Slot Assignment）自体が進化対象となる。Genome の生成規則を変えることとは別に、その用途を変更・追加する経路を担う。

### Profile = 発生により固定される文脈ベクトル
- **役割:** 「自分は何者か（どの組織の一部か）」という局所的な文脈を表す。
- **生成:** Genomeの出力フィールドの一部として、個体の発生（Development）プロセスの中で決定され、Cell生成後は固定される。
- **機能:**
    - Interpreterのスイッチング（解釈の切り替え）。
    - 共有された生成規則の異なる用途を、別の細胞文脈で共存させる。
    - 他者との相互作用におけるタグ（捕食・被食判定など）。
- **進化:** Profile の生成・選択規則を進化対象とする。これは、生成済みの Cell の Profile を生涯中に書き換えることとは区別する。
- **制約:** 万能細胞化を防ぐため、Profileにはコスト（維持コストや機能制約）が付随する。

### Cell = 行動・相互作用の実体
- **構成:** Mutableな `State` と、Immutableな `Profile` に加え、物理的な実体としての **`Composition`（構成物質）** と **`Inventory`（有限の内部容量）** を持つ。
- **発生と行動:** 近傍やFieldからの入力を、共有された Genome + Interpreter に通して次のアクションを決定する。細胞の振る舞いによる身体形成と、その身体での行動を共通の仕組みで扱う。
- **代謝と排泄:** 環境から物質を取り込み、それを分解・結合することでエネルギーを得る。利用されなかった物質は `Inventory` に老廃物として残る。容量が満杯になると新たな物質を取り込めなくなる（実質的な毒性／ペナルティ）ため、この物理的な制約からボトムアップに排泄行動が創発される。
- **増殖と身体の進化:** 自己複製には、自身を構成する `Composition` と同じ物質を `Inventory` 内に集める必要がある。ただし、理想の物質が不足している場合、別の物質で代用する「不完全な複製」を許容する。これにより、遺伝子だけでなく身体を構成する物理的な材質の多様化と進化を促す。

### Matter / Atom = 構造体としての物質システム
- **基本要素（Atom）:** 世界は最小単位の基本要素（初期状態では3種類程度）から構成され、それぞれに質量などの最低限の物理プロパティを持たせる。
- **構造体モデル:** 環境中の物質は、単一のIDではなく基本要素の結合体（例：A-B-C）として存在する。物質自体に固定のエネルギー値や毒性は設定せず、生命が物質の結合を分離・再結合する際の「相互作用の差分」としてエネルギーが産生される。これにより系の質量保存則を自動的に担保する。
- **遅延評価による「発見」:** 物質の多様性はオープンエンドとする。生命のInterpreterの突然変異により、未知の結合パターンや未知の要素へのアクセスが試みられた場合、極めて低い確率でそれが世界に「発見」され、環境中の無意味な背景物質と置換される。これにより、計算量の爆発を防ぎつつ無限の化学的探索空間を提供する。

### Field = 間接的相互作用と環境改変の基盤
- **役割:** 物理的な接触以外の「場」の相互作用を提供する。
- **現象:** 化学物質の拡散、熱、匂いなど、空間的な広がりと減衰を持つダイナミクス。
- **環境改変と土壌生成:** Cellの排泄物や、死滅したCellの `Composition`（死骸）がField上に堆積していく。これらが特定の物理的属性を持って環境に蓄積することで、生物と環境の複雑な相互作用（現実の土壌生成プロセスに類するもの）や、他種族との共生・捕食関係をボトムアップに駆動する。

### Agent = 進化と選択の単位
- **定義:** 同一の Genome と Interpreter を共有する Cell の集合体。
- **ライフサイクル:** 誕生、成長（多細胞化）、生殖（Genome と Interpreter、および Profile の生成・選択規則の継承）、死。個体内の細胞増殖と、子孫 Agent を作る生殖は区別する。
- **評価:** 明示的なフィットネス関数を持たない（Implicit Fitness）。「生き残って増えたものが正義」という環境下での適応を目指す。

## 3. 進化戦略のロードマップ（段階的な自由度の解放）

生成規則とその用途の進化を一度にすべて自由化せず、挙動を理解できる範囲から段階的に自由度を解放する（Curriculum Learning）。
これは探索と原因の切り分けのための実験方針であり、分離の主目的である生成規則の再利用とは区別する。
以下は解釈と文脈の自由度を広げる構想であり、実装の着手順は `roadmap_ja.md` に従う。

1.  **Phase A: プリセットの選択 (Discrete Selection)**
    - 最初からProfileやInterpreterを同時に連続値で進化させると、探索や結果の解釈が難しくなる可能性がある。
    - まずは、手動で設計された数種類の「プリセットProfile（筋肉型、センサー型など）」を用意し、Genomeは「どのProfileを選ぶか」だけを進化させる。
2.  **Phase B: スロット割当の進化 (Slot Assignment Evolution)**
    - Profileは固定のまま、Interpreterによる「どの出力をどのアクションに繋ぐか」の配線を自由化する。
3.  **Phase C: 完全な共進化 (Continuous Co-evolution)**
    - 最終的に、Profileのベクトル値そのものと、Interpreterの連続的なマッピング関数を同時に進化させ、未知の器官や機能の創発（Open-Ended Evolution）を目指す。

## 4. 最終的に目指す姿：文脈進化的システム

- **Genome** は、形態生成と行動制御に共通して利用できる生成規則を提供する。
- **Interpreter** と **Profile** は、その規則の異なる用途を文脈に応じて接続・共存させる。
- **World** は、行動の物理的な結果と、生存・再生産を左右する環境条件を提供する。
- この相互作用を通じ、獲得済みの能力を足掛かりにした新しい形態や機能が進化し、子孫へ受け継がれることを目指す。

目指すのは、個々の生き物を人間がデザインすることではなく、
**発生から行動までの進化の積み上げによって、多様な「ありえたかもしれない生き物」が生まれる世界**である。
