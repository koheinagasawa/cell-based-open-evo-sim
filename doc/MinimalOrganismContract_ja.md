# 最小個体実験の生命史と I/O 契約

**関連タスク:** `roadmap_ja.md` の P0-01

**状態:** P0-01 の契約は確認・承認済み。P0-02 に残す具体条件と区別し、実装済みを意味しない。

## 契約の一覧

以下は本書の承認済み事項の要約である。理由・制約・後続の未決事項は各節を参照する。

| 項目 | 初回の契約 |
|---|---|
| 対象 | 種 Cell から成長し、身体と基質の相互作用で2D を移動する個体 |
| 初期化・再発生 | world 原点の種 Cell 1個。発生座標・State・年齢はゼロ、結合なし |
| 継承・所有 | Genome、Interpreter、Profile 決定規則を継承。Agent 内で Genome と Interpreter を共有し、可変 State は各 Cell が所有する |
| Profile | 全 Cell 共通。誕生時に決め、生涯固定 |
| 入力18要素 | 発生座標2、自分の State 4、物理結合先の現在相対位置8、存在マスク4 |
| 出力9要素 | 次 State 4、出芽ゲート1、配置オフセット2、収縮・伸長1、基質抵抗1。Raw Vector を Interpreter が解釈する |
| State | 新しい Cell はゼロから開始し、更新は二相。相手の State は参照しない |
| 出芽・結合 | ゲートが0.5を超えたときに要求し、条件を満たせば親子間に物理結合1本を作る。各 Cell 最大4結合、入力4枠 |
| 成長の制約 | 有限の初期エネルギーと正の出芽コスト。子への無償エネルギー付与は行わず、総 Cell 数・step 数にも安全上限を置く |
| 発生・行動 | 最初から両方を許可し、同じ CPPN + Interpreter を使う。観察区間の境界で出芽停止や制御器切替はしない |
| 初回の対象外 | 明示的通信、State 交換、Field 入力、外部時刻入力、既存 Cell 同士の追加結合、自律生殖 |
| 後続の条件 | エネルギー分配・費用、物理法則、数値予算、区間の step 数、seed、baseline は P0-02 で確定する |

## 対象と問い

**承認済み（P0-01）:** 一つの種 Cell から結合した多細胞体へ成長し、
身体と環境の相互作用によって 2D 空間を移動する個体を最初の対象とする。
完成形や動作周期は指定せず、発生・行動を同じ CPPN + Interpreter で扱う。

問いは「発生した身体が、その後の行動に関わる経路を作れるか」である。
目指す証拠はまず機構の成立であり、この契約だけで進化、選択応答、自律生殖、OEE を確立しない。
餌への誘導、捕食、自律生殖は初回の対象外とする。
移動の具体的な物理機構と環境反作用は P0-02 で決める。
既存の位置を直接変更する `move` は、身体を介した移動の証拠に用いない。

## CPPN の自己座標

**承認済み（P0-01）:** 実空間の現在位置とは別に、Cell ごとに固定した
「発生座標」を CPPN の自己座標入力に使う。

| Cell / 時点 | 発生座標の決め方 |
|---|---|
| Agent 初期化時の種 Cell | 原点とする |
| 出芽で生まれる新しい Cell | 親の固定された発生座標に、出芽時の配置オフセットを足して決める |
| 誕生後 | 実空間で移動・変形しても変更しない |

ここで「誕生時」とは新しい Cell が生成される時点であり、既存の `bud` では出芽時に相当する。
これは同一 Agent 内の成長であり、子孫 Agent の生成とは区別する。
発生座標は祖先からの出芽オフセットを積み上げた文脈であって、
「誕生時の実位置から、最初の種 Cell の実位置を引いた座標」ではない。
現在の周囲の状態は、下記の「初回の入力配置」に定める物理結合近傍からの局所入力として別に扱う。

**理由:** 移動後の出芽に親の移動履歴を混ぜず、発生上の位置の手掛かりと現在の物理的な位置関係を分ける。
代案の world 現在座標や現在の個体重心からの相対座標は、移動・変形・成長で自己座標が変わるため、
今回は採用しない。発生座標だけで移動・回転不変性や再発生の頑健性が保証されるとは主張しない。
出芽オフセットは world の x・y 軸で表す。範囲と物理的な配置調整との関係は P0-02 で明示する。
その定義によって今回の固定座標の意図を保てなくなる場合は、この判断を再検討する。

## 既存実装との対応

- `simulation\agent.py`: Agent 内で Genome と Interpreter を共有して Cell を生成する基盤がある。
- `simulation\cell.py`: 現在の `sense()` は world 上の現在位置を入力する。上記の発生座標は未実装であり、
  導入時は既存実験の入力を黙って置き換えず、新実験の経路として区別する。Cell ごとの State と二相更新の基盤はある。
- `simulation\interpreter.py`: Raw Vector のスロット解釈と Profile 別の写像を扱う基盤がある。
- `simulation\policies.py`: 同一 Agent 内の出芽と、誕生時の Profile 選択を扱う基盤がある。
  現在の `BaseBudding` は親からコストを引き、子には別設定の `init_energy` を与える。
  下記の親からのエネルギー分配契約が実装済みとは扱わない。
- `simulation\physics\spring.py`: 現在のばねは通信にも使う `conn_out` の各辺から両端への力を計算する。
  物理結合近傍を、通信の送信先一覧とそのまま同一視しない。両者の意味の分離は P2-03 に接続する。

## Profile

**承認済み（P0-01）:** 初回は種 Cell と出芽した Cell のすべてに同じ固定 Profile を与える。
Profile は誕生時に決め、その Cell の生涯中は変更しない。
Profile の決定規則そのものの変異は、ロードマップどおり Phase 4 まで導入しない。

**理由:** 発生座標・局所入力・State による挙動差を使い、まず身体の発生と行動の経路に絞る。
複数の固定 Profile を誕生時に選ぶ案は、最初の機構確認には必須とせず今回は採用しない。
この構成では Profile による用途の使い分けや共存を検証できない。
文脈別の解釈を必要とする実験へ進む際に、複数 Profile の導入を再検討する。

## Cell State

**承認済み（P0-01）:** State は用途を固定しない4要素とする。
種 Cell と出芽した Cell はともにゼロで開始し、親 Cell の現在 State はコピーしない。
各ステップで Interpreter が Raw Vector から取り出した次 State を予約し、
全 Cell の更新計算後に同時に反映する二相更新を使う。
時間的な変化は Cell ごとの State の明示的フィードバックで表現する。

**理由:** 既存の4要素 State と二相更新を利用し、初期化と更新の方式を増やさない。
親の実行時 State を新しい Cell へ引き継ぐ案は今回は採用しない。
4要素は最小実験の選択であり、一般に十分な記憶容量であるとは主張しない。
次元や誕生時初期化の変更が必要になった場合は、I/O 契約の変更として別条件で扱う。

## 初期化・継承・観察区間

**承認済み（P0-01）:** 各 rollout は world 原点に置いた種 Cell 1個から開始する。
種 Cell の発生座標・State・年齢はゼロとし、結合を持たない。
Genome、Interpreter、Profile の決定規則を継承し、
成体の身体・Cell の現在 State・結合をコピーせず、子孫の rollout も種 Cell から再発生させる。
Agent 内で共有する Genome と Interpreter、および Cell ごとの可変 State の所有は、
`roadmap_ja.md` の中核契約に従う。

最初のステップから出芽と物理 Action の両方を許可し、同じ CPPN + Interpreter を使い続ける。
初期の発生観察区間と、その後の行動評価区間を設けるが、
区間境界で出芽を止めたり、別の制御器へ切り替えたり、成熟判定を必須としたりしない。
出芽の許可は成功の保証ではなく、以下の成長条件を満たした要求だけを実行する。
区間の step 数と評価開始 step は P0-02 で固定する。
行動評価中にも成長できるため、身体の移動と Cell 追加による重心変化を区別する計測方法も P0-02 で定める。

**理由:** 発生と行動を一つの生成・解釈経路で扱い、成体のコピーや外部の動作スクリプトに置き換えない。
外部 rollout の再初期化と予算の初期付与は実験側の足場であり、環境内での自律生殖ではない。

### 成長の予算

**承認済み（P0-01）:** 初回は有限の初期エネルギーと正の出芽コストを設け、
さらに総 Cell 数・step 数の安全上限を置く。出芽はエネルギー・結合数・総 Cell 数の条件を満たす場合だけ成功する。
最大4結合という局所上限だけを、個体全体の増殖を止める仕組みとは扱わない。
成長による子 Cell の誕生時にはエネルギーを無償で新規付与せず、親からの分配で扱う。
初回のために摂食・Field・代謝系一式を導入することは前提にしない。

**理由と限界:** 成長に使える量の制約と、実験を有限にする安全策を分けて保証する。
予算不足でも出芽要求を出し続けることはあり得るため、
制約で出芽できなくなることを「適切な成長停止が進化した」と解釈しない。
初期量、成功時の出芽コスト、親子への分配方法、他の Action の費用、維持費、
エネルギー不足時の行動・生死の扱い、総 Cell 数・step 数の具体値は P0-02 に残す。
エネルギーは今回の18要素入力には含めず、条件判定に用いる。入力への追加が必要なら契約変更として扱う。

## 局所入力の近傍

**承認済み（P0-01）:** 初回の最小構成は、空間的近傍の代わりに
物理的に直接結合した相手を近傍入力の対象とする。
これは CPPN の観測対象の選択であり、結合していない Cell との接触などを物理法則から除外する決定ではない。

**理由:** 近いだけの Cell と力を伝え合う結合先を区別し、身体と行動の関係を入力に反映する。
既存の空間的近傍を流用する35要素案は未承認の提案であり、今回の方針で置き換える。
物理結合は通信接続や相手 State の直接参照を自動的に許可するものではない。
空間的近傍は、非結合 Cell の感知を必要とする実験で再検討する。

**承認済み（P0-01）:** 固定長へのまとめ方は、結合先ごとの個別枠と
存在マスクを使う。結合先が入っている枠のマスクは1、空き枠は0とし、空き枠の情報はゼロ埋めする。
マスクは結合の伸びや力の大きさではなく、入力枠の有効性を表す。
結合ごとの方向や変形を区別するため、平均などへの集約方式は今回は採用しない。

**承認済み（P0-01）:** 初回は1 Cell あたりの最大物理結合数と固定入力枠数を一致させ、
全結合先を観測する。入力枠を超えた結合先を黙って切り捨てる部分観測は採用しない。
この上限は身体の局所的な結合数を制限する実験条件であり、身体全体の Cell 数上限とは別に扱う。
出芽時に親子間へ1本作る規則に合わせ、初回は最大4結合・入力4枠とする。
親との結合も数えるため、出芽で生まれた Cell はさらに最大3個の子と結合できる。
結合方向や角度を指定するものではなく、身体全体の Cell 数上限でもない。

**理由:** 身体と入力を対応づけやすくし、初回の機構確認に観測対象の選別や情報欠落という追加要因を持ち込まない。
固定数だけを観測する案は結合数を入力枠から切り離せるが、今回は採用しない。
結合の強さによる優先選択と残りの集約は、力学と感知の両方に選別パラメータが作用し、
比較すべき要因が増えるため後続の候補とする。
多数の結合が集中する身体構造が必要になった場合は、この局所上限と観測方式を再検討する。

4枠は旧35要素案の流用ではなく、今回の出芽・物理結合の規則に対して改めて承認した値である。
上限3でも枝分かれは可能だが、初回は分岐に少し余地を残すため4を選ぶ。
35要素という旧入力構成と、説明例の総数16 Cell は採用しない。

**承認済み（P0-01）:** 初回の結合先からの入力は現在の相対位置2要素だけとし、
結合先の内部 State は直接参照しない。結合の伸び、力、相対速度も独立の入力としては設けない。
自分自身の State 4要素とそのフィードバックは維持する。
State 交換や公開は後続で再検討し、結合先の State を含む34要素案は採用しない。

**理由:** 初回は2D の身体を介した移動を対象とし、内部状態の情報交換を追加せずに調べる。
State の直接参照も Cell 間の情報伝達であり、専用の送受信機構が不要というだけで「通信なし」と同一視しない。
これは実験条件の選択であって、State 交換なしで十分なロコモーションが進化すると保証するものではない。
相対位置は身体配置の観測であり、張力を直接観測する入力ではない。

### 初回の入力配置

**承認済み（P0-01）:** CPPN 入力は次の18要素とする。

| 入力位置（0始まり） | 内容 |
|---|---|
| 0–1 | 自分の固定された発生座標 |
| 2–5 | 自分の現在 State |
| 6–13 | 物理結合先4枠の現在の相対位置（各枠 x・y） |
| 14–17 | 各枠の存在マスク |

相対位置は、world の共通 x・y 軸・長さ単位で測った相手の現在位置から自分の現在位置を引いた値とする。
Cell ごとの回転座標系は導入しない。結合先数はマスクから分かるため独立入力にしない。
初回には Field・外部時刻・受信信号・他 Cell の State の入力を設けない。

各 Cell で結合が成立した順に空き枠へ割り当て、その結合が存続する間は枠を固定する。
出芽した Cell では親との結合が最初の枠に入り、その後に子との結合が入る。
種 Cell では最初の子との結合から枠を使う。空き枠の相対位置とマスクはゼロとする。
距離や角度で毎ステップ並べ替えず、身体の移動・変形だけでは入力枠の相手を変更しない。
これは局所的な入力枠の規則であり、既存の ID・乱数生成方式を変更する決定ではない。

**理由:** 結合相手と入力枠の対応を保ち、初回の観測と実装を単純にする。
この座標系に回転不変性はなく、その頑健性を確立したとは扱わない。

## 出芽と接続の意味

**承認済み（P0-01）:** Interpreter は Raw Vector から出芽ゲート1要素と
配置オフセット2要素を取り出す。ゲートが0.5を超えたときに出芽を要求し、
1 Cell の1ステップあたり最大1個の子を作る。ゲートは要求の有無であり、上限や予算の条件を迂回しない。
オフセットは world の x・y 軸で表し、親の現在位置からの子の配置と、
親の固定発生座標からの子の発生座標に使う。
配置距離の許容範囲と重なりの扱いは P0-02 の物理条件で決める。
これは既存の `BaseBudding` の3要素形式とゲート判定に合わせた選択であり、
スカラーゲートだけからランダムなオフセットを生成する既存の別経路は初回の契約に採用しない。
Raw Vector 内の各出力の位置は、下記の出力配置に従う。

**承認済み（P0-01）:** 出芽した Cell と親 Cell の間に物理結合を1本作る。
その結合は両端に作用し、両端それぞれの近傍入力で1枠を使う。
初回は既存 Cell 同士の追加結合・再結合・同じ相手との多重結合を導入しない。
種 Cell から出芽だけで成長する間、物理結合は木構造となり、輪や網目は作れない。
これは完成形の指定ではなく、生成できる身体構造への実験上の制約である。

本書では、身体 topology は Cell 群の構成・配置とつながり、物理結合は力を伝える Cell 間の辺、
通信接続は信号を届ける方向付きの辺、CPPN graph topology は共有 Genome 内のノード・辺を指す。
これらを同一のグラフとは扱わない。初回の身体のつながりは親子の物理結合で作り、通信接続は導入しない。

**承認済み（P0-01）:** 親 Cell が最大4結合に達している場合、その出芽要求だけを不成立にする。
子 Cell と結合を生成せず、出芽の実行費用も徴収しない。親の通常の State 更新や他の行動は継続する。
正常な制約による不成立として理由を記録し、実験全体のエラーとは扱わない。
一方、実際の結合数が4を超える実装上の不整合はエラーとして扱う。
この決定は結合上限による不成立の扱いであり、成功時の費用や他の予算条件の具体値は P0-02 に残す。

**承認済み（P0-01）:** 物理結合と通信接続は意味を区別する。
物理結合は力や変形を伝え、通信接続は送信側の CPPN 出力を Interpreter が解釈した信号を届ける。
物理結合先の観測は相手の内部 State の直接参照や信号受信を自動的に含まない。
通信を導入する場合も、受信信号は同じ Cell の CPPN への入力とし、通信専用の別 NN を必須としない。

**理由:** 身体の物理状態の観測と、明示的な信号交換を混同しないため。
物理と通信の接続相手や生成契機が一致することは許容するが、
物理的な結合の強さと通信の重みを自動的に同一視しない。
既存の `conn_out` の兼用を、両者が同じ意味である根拠とは扱わない。

**承認済み（P0-01）:** 初回の最小実験には明示的な通信を導入しない。
通信接続を生成せず、CPPN の受信信号入力と Interpreter のメッセージ送信出力も設けない。
物理結合を介した力・変形と、その局所的な観測による相互作用は残す。
既存実験の通信機能を削除する決定ではない。

**理由と再検討条件:** 初回は身体を介した発生・行動に絞り、信号交換の自由度を増やさない。
Field 等を使った環境センシングを導入してから、感知した情報の共有に通信が必要かを再検討する。
これは今回の実験の導入順であり、通信一般に Field が必要という意味ではない。
出芽時の親子間への通信自動接続は後続の候補に留める。
将来導入する場合の方向、信号の次元、受信方法・時点、接続の除去規則は、その時点の契約で定義する。

## 身体 Action の方向

**承認済み（P0-01）:** 初回は2D の基質上で、結合の目標長を変える収縮・伸長と、
Cell の基質に対する抵抗の強弱を制御する方向で具体化する。
身体の変形と環境反作用を通して移動を生じさせ、位置を直接変更する `move` はこの経路に用いない。
どの Cell を滑りにくくし、どこをいつ収縮させるかの順序・周期は手で与えず、
発生と共通の CPPN + Interpreter の出力に任せる。

**理由:** 一様な overdamped 更新で内部力だけを作用させても、成長などがない条件では
重心移動につながらないため、基質との相互作用も制御対象にする。
これは最初に試す機構の選択であり、ロコモーションの進化を保証するものではない。
既存の受動ばねと一様な位置更新は、この能動的な機構の実装済み証拠とは扱わない。

**承認済み（P0-01）:** 収縮・伸長の指令と基質への抵抗の指令は Cell ごとに各1要素とする。
収縮・伸長の指令はその Cell の全物理結合に共通で、各結合の目標長には両端 Cell の指令を反映する。
初回は同じ Cell が結合ごとに異なる指令を出す自由度を設けない。
基質への抵抗の指令は、その Cell 自身の基質との相互作用に使う。
